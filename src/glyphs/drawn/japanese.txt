// Kanji and kana drawn by hand on a grid (pixel.JAPANESE, build.pinned):
// placed by phase, they read as another character, or lose a stroke the
// grid has room for. Each keeps the bottom row it stood on
// (pixel.pixelate_font) and its ink within its advance; on 100, it leaves
// the top row of its em free, as most kanji do, so that in vertical text
// it meets nothing above it. Regular and Italic share their Noto Serif
// JP, so are drawn alike; Bold's kanji and kana are not placed by phase
// (family.light), so none are drawn. On 100, the vertical forms of the
// kana take the cells of their horizontal ones, these included
// (pixel._follow).
//
// A glyph is a line "grid styles character x,y", x,y its bottom left cell
// (the baseline is y 0), then its cells, top row first: "#" ink, "." air.
