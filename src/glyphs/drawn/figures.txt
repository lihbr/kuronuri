// a cell a row, each row's cell touching the one below it, over the height
// fractions span (the bottom of denominators to the top of numerators,
// 0..700), as wide as MCKL's smooth Italic slash is for that height (626
// for 700): where it steps up without stepping across, in the middle.

// each, the same in Regular and Bold), one cell a row, in each grid's
// rhythm: on 50 a cell repeated every third row, on 70 the step below
// repeated, as on 100.
//
// A glyph is a line "grid styles character x,y" (styles separated by
// commas), x,y the cell its bottom left cell is in, then its cells, top row
// first: "#" ink, "." air. Lines starting with // are notes.
